This repository contains complete solutions for all 4 AI tasks from the CodeAlpha AI Internship program.

| Task | Title | Technologies |

| **Task 1** | Language Translation Tool | Flask, Google Translate API, gTTS |
| **Task 2** | FAQ Chatbot | Flask, NLTK, TF-IDF, Cosine Similarity |
| **Task 3** | Music Generation with AI | TensorFlow/Keras, LSTM, music21 |
| **Task 4** | Object Detection & Tracking | OpenCV, YOLOv8, Custom SORT Tracker |

### ✨ Features

**Task 1 - Language Translation:**
- Auto language detection
- 100+ languages supported
- Text-to-speech functionality
- Copy to clipboard

**Task 2 - FAQ Chatbot:**
- NLP preprocessing (tokenization, lemmatization)
- TF-IDF vectorization
- Cosine similarity matching
- Interactive chat UI

**Task 3 - Music Generation:**
- MIDI file parsing with music21
- 3-layer LSTM neural network
- Temperature-controlled generation
- MIDI output generation

**Task 4 - Object Detection:**
- Real-time webcam/video support
- YOLOv8 object detection
- Custom SORT-like tracking
- Persistent track IDs
